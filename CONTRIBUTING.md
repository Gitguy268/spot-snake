# Contributing

Thanks for helping with Spot's Biscuit Snake.

By taking part you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting a bug or asking for a feature

Open an [issue](https://github.com/Gitguy268/spot-snake/issues/new/choose) and use the template. For a bug, say which browser and version, what you did, what you expected and what happened.

Report security problems privately: see [SECURITY.md](SECURITY.md).

## Making a change

1. Fork the repository and create a branch from `main`.
2. Set it up and run it:

   ```sh
   open index.html    # or serve the folder with any static file server
   ```

3. Make your change. Keep commits small, each with a clear message.
4. Run the checks below and update the README if behaviour changed.
5. Open a pull request and fill in the template.

## Checks

There is no build and no test suite. Open `index.html`, play a round with the keyboard and once with touch or the on-screen buttons, and check the browser console stays clean.
